# Security and authorized use

Software published by [HackerX Official](https://github.com/HackerX-offical) is intended for
**defensive security research, authorized penetration testing, and education** with explicit
permission on the systems you test.

- Do not use these tools against systems you are not authorized to assess.
- Comply with applicable laws and contractual scope.
- Report vulnerabilities in this repository via GitHub Issues (no public exploit drops).

For coordinated disclosure involving HackerX projects, open an issue with reproduction steps
and impact; allow reasonable time for remediation before public disclosure.
